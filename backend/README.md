# Backend API

A simple Rust Actix-web backend API.

## Prerequisites

- [Rust](https://www.rust-lang.org/tools/install) (1.70+ recommended)

## Running the Server

```bash
cd backend
cargo run
```

The server will start at `http://127.0.0.1:8080`.

## Endpoints

- `GET /` - Returns "Hello, World!"
