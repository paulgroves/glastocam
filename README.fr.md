# Glastocam

Version plein écran de la webcam de Glastonbury - https://glastocam.foobarlol.lol

## Fonctionnalités

- 🖼️ Affichage plein écran de la webcam du festival de Glastonbury
- 🔄 Actualisation automatique de l'image toutes les 5 minutes
- 📍 Défilement automatique vers le point de vue optimal
- 📄 Plan du site 2016 inclus en PDF pour référence

## Utilisation

Ouvrez simplement `index.html` dans votre navigateur pour voir le flux en direct de la webcam Panomax de Glastonbury.

Aimez la ferme, ne laissez aucune trace 💚
